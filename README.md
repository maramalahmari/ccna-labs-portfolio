# ccna-labs-portfolio

This repository contains hands-on CCNA labs implemented for learning and portfolio purposes.
The labs focus on IPv4/IPv6 addressing, subnetting, routing fundamentals, and verification.

## Labs

| # | Lab Title | Topics |
|---|----------|--------|
| 01 | Boson Challenge Lab 1 – IPv4 & IPv6 | Subnetting, IPv4, IPv6 SLAAC, EUI-64 |

## Tools
- Cisco Packet Tracer (Portfolio Implementation)
- Boson NetSim (Practice & Validation)

## Focus Areas
- IPv4 subnetting (/30, /28, /32)
- IPv6 addressing & SLAAC
- Network device configuration & verification
- Documentation and troubleshooting
